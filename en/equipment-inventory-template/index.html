Inventory template for film equipment, in Excel.

A free Excel sheet, with no registration, containing the columns that a production company or a rental house needs for its equipment inventory. It works on its own and, if you later want to move to Bulx, it can be imported without changing anything.

What it does

Inventory template, in detail.

Code and name

One code per item (for example, CAM-0001) and its name. The name is the only required column; the code is used for the label and to avoid duplicates.

Category and subcategory

In a single column, with the full path separated by ‘ > ’: ‘Lighting > Stands’. This allows the inventory to be filtered and sorted by department.

Quantity

The number of units of that item. For gear with a serial number, one row per unit is advisable; for consumables or identical parts, one row with the quantity.

Price per day

The rental rate for each item, which is the basis of any quote priced by the day.

Serial number and location

The serial number identifies each unit for insurance or repair purposes; the location says which warehouse, shelf or case it is in.

Department and notes

The department it belongs to (camera, lighting, grip, sound) and any remarks: accessories included, condition, purchase date.

Getting started

Three steps to get started.

  1. 1

    Download and fill in

    One row per item, without changing the headers. The second sheet explains each column.

  2. 2

    Keep it up to date

    Every addition, removal or change of location is noted in the same sheet.

  3. 3

    Import it into Bulx, if you wish

    Bulx reads the template as it is, creates the categories and assigns a QR label to each item.

FAQ

Frequently asked questions.

If your question is not here, write to info@bulx.es.

Is the template free?

Yes. It can be downloaded without registration and used and modified freely.

Which programs open it?

Microsoft Excel, Numbers and Google Sheets. It is an .xlsx file without macros.

Which columns are required?

Only the name. The rest can be filled in gradually.

When does an Excel sheet stop being enough?

When you need to know who has each item and since when, to prevent something being reserved twice for the same dates, or to record the condition in which gear comes back. A sheet holds the list, not the movements.

Can it be imported into Bulx?

Yes. The template headers are the ones Bulx reads. Before importing, Bulx shows which items will be added and which categories will be created.
